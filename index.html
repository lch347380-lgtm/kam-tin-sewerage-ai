Source-controlled checks for the Kam Tin sewerage FYP model

Source hierarchy: the uploaded Stormwater Drainage Manual, Fifth Edition (2018) is a stormwater document. This sanitary sewerage model therefore uses the DSD Sewerage Manual Part 1 as the primary sewer-design source and EPD GESF for sewage-flow estimation. SDM 2018 values are used only where they are applicable as common buried-pipeline / coordination cross-checks, such as the cover-depth screen.
